# Roadmap

7. **Current release candidate:** optional No AI / local Ollama / OpenAI API assistance with secure Windows credential storage, explicit cloud consent and payload preview, bounded structured Responses API calls, honest accounting/errors, mocked verification, CI, and an unsigned prerelease. Assistance remains review-only and optional.

Next proposed scope: clean-machine Windows qualification, accessibility/DPI coverage, and a signing/distribution decision. Do not add autonomous execution authority, silent provider fallback, real-provider CI, or automatic uncertain-run recovery.

Milestones 0–6B are implemented. Milestone 6B adds an unsigned assisted offline NSIS installer with an explicit E: destination, data-preserving upgrade/uninstall/reinstall behavior and isolated same-machine lifecycle verification. Same-machine verification is not clean-machine verification.

0. Local library/editor, validation, SQLite migrations/revisions and actual desktop checks.
1. Dedicated Chromium/MV3 recording, session-bound validation, review and editable drafts.
2. Target provenance, preferred locators/read-only inspection, stable/shared inputs, deliberate checks, actionable validation and immutable evidence.
3. Supervised single-record execution, immutable pre-run snapshot, separate worker, per-origin approval, pause/resume/stop and durable honest outcomes. This deliberately preceded CSV to verify one row before multiplying actions.
4A. CSV preparation: maintained background parser, strict string preservation/bounds, explicit revision mapping/constants/trim, paged resolved validation, saved datasets/mappings and no-action preview. Completed and verified before connecting execution.
4B. Supervised sequential batches: exact immutable included/excluded rows/inputs/origins/settings, explicit approval, shared single-row engine, exclusive browser ownership, default pause-on-error, mandatory uncertain pause, durable row/step history, exception notes/filtering and protected JSON/CSV summaries. Only never-dispatched remaining rows may enter a new acknowledged review after confirmed worker exit. No automatic retry or restart.
5. Optional bounded local configuration assistance through existing loopback Ollama and `qwen3:8b-q4_K_M`, with explicit review/acceptance, deterministic offline guidance and no execution authority. The active-batch native close gap is also covered by actual Cancel/Confirm verification.
6A. Unsigned unpacked Windows candidate: production resources/workers/extension/samples, isolated E: writable state, external browser readiness, no source/dev-server dependency, actual packaged record/restart/batch/export verification.
6B. Unsigned Windows installer candidate: assisted E: destination, no forced launch/shortcuts/downloads/data deletion, 0.6.0→0.6.1 upgrade, uninstall retention and reinstall verification against isolated synthetic data.

Stop after Milestone 6B. The completed source may be checkpointed and pushed under the current explicit handoff authorization; no release, signing purchase, model activity, reconciliation, automatic retry or publication is authorized. Clean Windows VM/account qualification, SmartScreen/antivirus testing, optional signing and any release decision require separate authorization. No exactly-once or automatic reconciliation claim has been established.

Richer browser support, unattended operation, installers/signing and distribution require separate scope/authorization. Everyday browser profiles are never used; core functionality requires no model or paid service.
